# Arduino Smart Ultrasonic Parktronic System

Компактная система автомобильного парктроника на базе микроконтроллера Arduino Uno, ультразвукового сонара HC-SR04, пьезоизлучателя и светодиодной индикации.

## 📌 Описание проекта
Устройство измеряет расстояние до приближающихся препятствий в реальном времени. При вхождении объекта в опасную зону (< 75 см) активируется динамическая звуковая и световая сигнализация.

## ⚡️ Ключевые особенности
- **Точный расчет расстояний**: Вычисление дистанции в сантиметрах по формуле из официального даташита сонара HC-SR04 (`duration / 58.0`).
- **Динамическая частота писка**: Паузы между звуковыми сигналами рассчитываются автоматически на основе текущей дистанции (`delay(distance * 10)`). Чем ближе стена — тем быстрее пищит система, полностью имитируя реальный автомобильный парктроник!
- **Аппаратная генерация звука (`tone()`)**: Использование функции `tone()` на частоте 800 Гц для чистого аудиосигнала тревоги.
- **Защита цепи**: Использование токоограничительного резистора 220 Ом для безопасной работы светодиода.

## 🛠 Используемые компоненты и технологии
- **Микроконтроллер**: Arduino Uno
- **Периферия**: Ультразвуковой сонар HC-SR04, Пьезоизлучатель (Buzzer), Красный светодиод, Резистор 220 Ом
- **Язык**: C++
- **Симуляция**: Wokwi Simulator

## 🔌 Схема подключения (Pinout)
- **HC-SR04**: `TRIG` -> Pin 11, `ECHO` -> Pin 10, `VCC` -> 5V, `GND` -> GND
- **Buzzer**: `+` -> Pin 13, `-` -> GND
- **LED**: `Анод (+)` -> Pin 12, `Катод (-)` -> Резистор 220 Ом -> GND
